# 股票行情追踪器 (Stock Tracker)

## 简介
这是一个基于 Python 的命令行股票行情追踪与分析工具。它集成了中国 A 股 (Baostock) 和美股 (Yahoo Finance) 的数据源，提供实时行情查看、自选股管理、以及基于 AI 的市场总结功能。界面采用 `Rich` 库构建，美观且交互友好。

## 主要功能
- **多市场支持**: 支持 A 股 (CN) 和 美股 (US)。
- **稳定数据源**:
  - A 股列表基于 **Baostock** (支持自动回溯最近交易日，解决周末/节假日无数据问题)。
  - 美股列表基于 **Wikipedia (S&P 500)**。
  - 实时行情基于 **YFinance** (Yahoo Finance)。
- **智能自选股管理**:
  - 支持 **模糊搜索** 添加 (支持中英文名称、代码，如 "Apple", "万达", "000001")。
  - 自动识别代码冲突 (如 `000001` 上证指数 vs 平安银行)。
  - 本地持久化存储数据。
- **市场概览**:
  - 分页浏览市场所有股票。
  - 支持 **页码跳转** ([j]指令) 快速定位。
  - 采用懒加载模式，大列表也能秒级响应。
- **AI 智能总结**:
  - 调用 OpenAI 兼容接口生成的财经日报。
  - 自动分析自选股涨跌趋势。
- **美观 UI**: 使用 Rich 库实现的现代化终端界面，支持彩色涨跌幅显示、加载动画等。

## 环境要求
- Python 3.8+
- 依赖库: `rich`, `yfinance`, `baostock`, `openai`, `pandas`, `python-dotenv`, `lxml`

## 安装

1. **克隆项目**
   ```bash
   git clone <repository_url>
   cd <repository_directory>
   ```

2. **创建并激活环境 (推荐)**
   ```bash
   conda create -n stock_tracker python=3.10
   conda activate stock_tracker
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

## 配置

在项目根目录创建 `.env` 文件，配置下列环境变量 (主要用于 AI 总结功能):

```ini
# OpenAI API 配置 (支持兼容接口，如 DeepSeek, ECNU-API 等)
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

*注意: 基础行情功能 (查看价格、列表) 不需要 API Key 即可使用。*

## 运行

```bash
python main.py
```

## 操作指南

| 按键/选项 | 功能描述 |
| :---: | --- |
| **[1]** | **查看自选股**: 列表展示关注股票的最新价、涨跌幅、成交量。 |
| **[2]** | **添加自选股**: 输入关键词 (名称/代码) 搜索并添加。支持输入 `D` 进入直接代码输入模式。 |
| **[3]** | **删除自选股**: 移除不再关注的股票。 |
| **[4]** | **个股详情**: 查看股票的详细信息及近一个月历史 K 线数据。 |
| **[5]** | **AI 总结**: 根据当前自选股表现生成文字版简报。 |
| **[6]** | **市场列表**: 分页浏览全市场。支持 `n`(下页), `p`(上页), `j`(跳转)。 |
| **[q]** | **退出**: 退出程序。 |

## 数据源说明
- **A 股列表**: 每日首次运行会自动从 Baostock 更新最近交易日的 A 股列表并缓存。
- **美股列表**: 仅包含 S&P 500 成分股 (从 Wikipedia 获取) 以保证搜索稳定性。非标普500股票可直接通过代码添加。
- **实时价格**: 可能会受到 Yahoo Finance API 频率限制，程序已做一定延时处理，但频繁刷新可能导致短暂失效。
